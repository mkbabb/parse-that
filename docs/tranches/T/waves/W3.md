# T.W3 — diagnostics, recovery, and commitment

## Goal

Produce deterministic per-run diagnostics and give recovery/backtracking a named,
transactional control algebra.

## Work

1. **Always collect evidence.** Furthest offset and expected labels are semantic
   failure data; rendering extras are selected by parse options because a global
   enable switch changes results across callers.
2. **Outcome-local recovery.** Recovery consumes exactly the returned child failure
   and emits entry-relative diagnostics; it never selects ambient furthest evidence
   or leaves recovered control attached to a later failure.
3. **Choice identities and control tokens.** Only grammar choice allocates a visible
   run-local identity. Cut targets that exact live owner; sequence propagates it,
   the owner discharges it once, and repetition/lookahead/recovery/memo/LR machinery
   cannot masquerade as a user choice.
4. **EOF parity.** Route empty-input and end-of-input leaf failures through the same
   evidence path because early returns currently omit expected labels.
5. **Structured rendering.** Keep line/column/source excerpts as a pure projection
   from source plus qualified offsets because console side effects and cached text
   do not belong to parsing.
6. **Recovery laws.** Test nested, sibling, committed, repeated, and thrown callback
   cases because each stresses a different transaction boundary.

## Gates

- Concurrent and nested parses never exchange diagnostics.
- Replaying one result through the renderer is byte-identical and side-effect free.
- Every leaf, including EOF, reports a qualified furthest position and expected set.
- A cut prevents only the intended choice scope; lookahead and recovery cannot leak
  commitment outward.
- Recovery checkpoints preserve outer diagnostics and discard abandoned inner
  transactions exactly once.
- Recovered-cut, cut-through-repetition, nested/sibling choice, stale/double-token,
  and sequential-recovery counterexamples satisfy an independent control trace.

## Completion

Global diagnostic functions and parser-side console output are deleted; the public
result is the single diagnostic authority.
