# T.W4 — memoization and left recursion

## Goal

Transpose packrat and left-recursion machinery into invocation ownership without
regressing the grammar classes it currently handles.

## Work

1. **Run-owned terminal tables.** Move memo cells, SCC heads, generations,
   worklists, reverse dependencies, and LR stacks behind a lazily created run
   member because process-global epochs caused cross-source and nested-reset defects.
2. **Structured keys.** Use parser-id -> offset maps rather than float-composed keys
   because structural maps remove mantissa budgets and make ownership visible.
3. **Private memo entry.** Memo wrappers invoke only the private executor because
   public raw application can never establish source ownership.
4. **Transitive cache policy.** Seal-time SCC effect closure identifies diagnostic,
   recovery, cut, and rule dependency. Ordinary memo rejects transitive rule/cut
   dependencies; cut-bearing nonrecursive rules execute uncached and recursive SCCs
   with outward cut are rejected until a smaller correct policy is proved.
5. **LR generation worklist.** Grow `(sealed SCC, entry)` with monotone generations,
   reverse dependencies, and late participant admission. Preserve direct, indirect,
   mutual, multiple-head, mixed, nullable, late-reached, exception, rollback, and
   nested cases against an independent finite-approximant grammar oracle.
6. **Budget evidence.** Measure lazy table allocation and cell growth; add per-run
   limits that return non-backtrackable resource failure. Every success/failure/
   exception/budget exit terminalizes or evicts all reachable participants; no
   `Evaluating`/`Growing` partial answer can escape.

## Gates

- Two different sources, two nested invocations, and two interleaved invocations
  cannot share a cell by construction.
- Existing left-recursion fixtures and new randomized grammar/input comparisons
  match a non-memo oracle where that oracle terminates.
- No global mutable packrat variable or reset API remains.
- Memo-disabled parses allocate no memo table.
- Memo budget exhaustion is deterministic, typed, and cannot return a partial
  successful value.
- Every cell transition and worklist generation satisfies the sealed trace
  invariants; post-run debug census reports zero transient cells.
- The bounded exhaustive/generated oracle has zero discarded cases and zero VM
  discrepancies over success/failure, offset, committed owner, and expected labels.

## Completion

The old epoch latch, key arithmetic, reset function, and raw-bypass tests are
deleted with their implementation; replacement external laws stay.
