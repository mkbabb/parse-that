# T.W1 — invocation-owned kernel

## Goal

Land the smallest execution carrier in which one parse call owns all mutable
semantics and parser definitions are immutable, shareable values.

## Work

1. **Sealed definition/run split.** Make `Parser<T>` an opaque typed reference into
   a fully sealed immutable definition graph. Sealing resolves rules, rejects
   dangling/multiple definitions, computes call SCCs/reverse edges/transitive
   effects, and removes lazy body construction from execution.
2. **One `Run` context.** Own source, cursor, value slot, failure evidence,
   diagnostics, recovery log, commit scope, and lazily allocated memo state in one
   internal object because module globals cannot express invocation boundaries.
3. **Typed transactions.** Snapshot scalar execution/control state plus a journal
   mark. Sparse writes use a closed typed undo-record union with one first-write
   record per address/transaction; no closure journal. Commit compacts records and
   an invocation with no live checkpoint has an empty journal.
4. **Explicit outcomes.** Node evaluation returns success, local failure evidence,
   or non-backtrackable resource failure. Choice alone merges sibling evidence;
   recovery never reads an ambient winner.
5. **Private executor.** Remove raw public application; internal modules receive a
   package-private call capability because bypassing invocation construction also
   bypasses memo and diagnostic ownership.
6. **Allocation comparison.** Compare mutable single-run context, persistent result
   threading, and compact instruction-frame prototypes on short and long inputs
   because elegance alone does not choose the hot representation.
7. **Iterative execution.** Interpret sealed nodes with an explicit continuation
   stack so deep right recursion is heap-bounded rather than host-stack recursion;
   all throws unwind through one terminal cleanup path.

## Gates

- Cross-source, nested, reentrant, exception-unwind, and interleaved invocations are
  isolated without reset calls.
- `Object.keys(parser)` and public typings expose no execution state or executor.
- Transaction round-trip and independent trace verification cover every mutable
  address, stack, control token, and terminal path; no undo closure is retained.
- A failed branch restores operational state and retains only explicitly merged
  evidence.
- Default non-memo parse allocations do not regress beyond the measured budget;
  the exact budget is fixed from paired samples, not inherited as 15%.
- Right recursion over 100,000 tokens completes without `RangeError`; terminal
  execution leaves no frame, choice, checkpoint, head, or journal entry.

## Completion

W2–W4 can build exclusively on the new run/checkpoint contract; no old executor or
state path remains.
