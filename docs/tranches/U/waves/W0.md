# U.W0 — make memory and regex lies executable

## Goal

Turn every adjudicated PT-K/PT-R defect into a deterministic failing witness
before changing production code.

## Work

1. Add safe-API tests proving forged/out-of-range/reversed/cross-source spans,
   absent padding, wrong erased contexts, recursive lazy access, and parse throws
   cannot reach unchecked indexing, aliasing, or stale invocation state.
2. Add regex vectors for start/end and line anchors, greedy versus lazy ordering,
   captures, invalid escapes, Unicode properties/classes, empty repetitions, and
   catastrophic ambiguity with explicit budgets.
3. Reproduce direct-table and generated-parser disagreement and the invalid
   bootstrap command from an empty target directory.
4. Census every unsafe block with caller proof, invariant owner, and a safe
   counterexample; absence of a proof means delete/redesign, not a comment.
5. Record RSS/allocation/throughput baselines on fixed corpora without turning
   incumbent speed into semantic authority.

## Gates

- Every witness is RED for exactly its named defect on `ef10d5b`.
- Sanitizer/Miri-capable subsets and ordinary Apple/aarch64 suites have recorded
  commands; unsupported configurations are explicit rather than silently skipped.
- Fixtures and expected results are stable across two runs.
- Two hostile critics and an adjudicator rule the completeness of the witness bank.

## Completion

PT-K and PT-R remain RED, but no known defect is merely prose and each later wave
has an independent oracle capable of rejecting a superficial repair.
