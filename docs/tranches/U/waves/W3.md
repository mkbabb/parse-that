# U.W3 — one regex syntax and HIR

## Goal

Define the complete regex language once and lower it losslessly to canonical HIR.

## Work

1. Write the syntax contract for literals, escapes, concatenation, alternation,
   groups, captures, classes, ranges, Unicode properties, repetition greediness,
   and assertions with exact diagnostic positions.
2. Select one generated parsing route. Direct handwritten tables may remain only
   as a provisional differential oracle and are deleted when the generated route
   closes; both never ship.
3. Make anchors/assertions explicit HIR nodes, lazy polarity explicit on
   repetition, captures stable and ordered, and invalid constructs typed errors.
4. Pin a Unicode version and generate property/class tables with source and output
   digests. Unknown names and invalid escapes fail; none become NUL or catch-all.
5. Canonicalize only semantics-preserving structure. Every rewrite exposes all
   children and has an exhaustive/property witness over language and captures.
6. Re-form `syntax` and `hir` modules by invariant; break parser-parent cycles and
   move all tests to their isomorphic external homes.

## Gates

- U.W0 syntax/Unicode/assertion/laziness witnesses pass.
- Differential vectors against regex-automata and the approved JS face agree where
  contracts overlap; intentional differences are named fixtures.
- Parse-print-parse preserves canonical HIR and diagnostics are deterministic.
- No silent catch-all, NUL substitution, duplicate syntax parser, or unpinned table.

## Completion

PT-R has one complete syntax-to-HIR authority suitable for both execution and
grammar-driven bootstrap.
