# U.W8 — GESTALT-P1 whole-repository iteration

## Goal

Test whether all individually green locks form one coherent, directed,
maintainable parse-that product.

## Work

1. Extract the complete typed graph: Cargo/packages/features, Rust modules/uses/
   reexports/includes/cfgs, TS runtime/type/reexports/exports, tests, grammar and
   generator edges, artifacts, packed consumers, and documentation authority.
2. Partition the graph dynamically by SCC, articulation, fan-in/out, ownership,
   generated provenance, and behavior clusters. Do not use fixed file counts.
3. For every cluster dispatch two fresh Sol hostile critics and a fresh Sol
   adjudicator. Review every node and edge; accepted findings are implemented and
   re-extracted before the cluster can close.
4. Audit Goldilocks structure: no god module, sand farm, module-name stutter,
   co-located production test, sibling-major duplicate, or hidden legacy route.
5. Run semantic, fuzz/property, clean regeneration, package, Miri/sanitizer,
   allocation, throughput, cold-start, and value.js gates twice.

## Gates

- Every graph node and edge belongs to a reviewed cluster; unsupported extraction
  dimensions are RED rather than omitted from totals.
- No nontrivial shipping SCC crosses an ownership boundary.
- All accepted P1 findings are corrected and incident clusters rerun.
- One complete post-correction audit reports zero unresolved fact.

## Completion

GESTALT-P1 produces an immutable candidate and a full supersession ledger. It is
not tranche completion; U.W9 assumes P1 is still wrong.
