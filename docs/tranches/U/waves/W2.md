# U.W2 — one scanner contract, honest Apple acceleration

## Goal

Consolidate structural, quote, whitespace, number, and Unicode scanning behind
one safe contract and retain specialization only where Apple/aarch64 evidence wins.

## Work

1. Inventory duplicated scanners in parse_that, regex, bootstrap, generated
   parsers, and bbnf constellation consumers; define one input/output contract for
   each genuinely distinct operation.
2. Implement the scalar reference first with boundary, tail, invalid UTF-8, and
   short-input semantics. Add NEON only for measured hot kernels and use runtime or
   compile-time selection that exists on supported Apple targets.
3. Delete all x86 cfgs, features, intrinsic paths, benchmarks, docs, and generated
   references. Delete functions named `neon` that merely call scalar code.
4. Fuse passes only when the combined state machine stays smaller and property-
   equivalent; keep separate scans when fusion creates a god kernel.
5. Route regex and parser consumers directly to the canonical operations in the
   same change that deletes their duplicates.

## Gates

- Scalar/NEON results are byte-equivalent on exhaustive short inputs and generated
  boundary corpora; sanitizers and guard-page tests cover tails.
- Repository-wide authored/generated/config scan finds no x86 vocabulary.
- Benchmarks include distributions and allocations; every retained accelerated
  kernel wins a named corpus without regressing small inputs materially.
- The scanner module graph is acyclic and every exported operation has at least
  two real consumers or a semantic reason for singularity.

## Completion

PT-K scanner ownership is GREEN: one safe reference, only honest Apple-specific
specializations, and no duplicate or architectural theater remains.
