# U.W1 — checked Rust run and span kernel

## Goal

Make safe Rust APIs unable to construct invalid input views, spans, contexts, or
recursive execution state.

## Work

1. Replace freely constructible spans with source-qualified checked ranges;
   slicing returns a typed error unless construction already proves the range.
2. Replace erased context casts with a typed invocation-owned run/arena. Parser
   definitions are immutable; all mutable cursor, diagnostics, recovery, memo,
   and recursion state belongs to one call.
3. Remove the padded empty-vector/default witness and full-input padding copy.
   Any remaining padded view has one validating constructor and no safe unchecked
   access. Prefer bounds-check elimination the optimizer can prove.
4. Replace `UnsafeCell` lazy aliasing with an explicit safe recursion cell or
   sealed arena protocol whose states and borrow rules are testable.
5. Make furthest-error aggregation invocation-local and deterministic. Panics,
   poison, and callbacks unwind without retaining state.
6. Organize production by `run`, `combinator`, and `value` invariants; move tests
   into matching external paths and strip redundant module-name prefixes.

## Gates

- The U.W0 invalid-construction bank fails closed through public APIs.
- Miri-capable tests report no undefined behavior; no safe function contains an
  unproved unchecked slice, pointer cast, or aliasing boundary.
- Nested, concurrent, repeated, panicking, and cross-source parses are isolated.
- Differential JSON/CSS/CSV values, spans, and diagnostics match the approved
  corpus or carry an explicit breaking-contract ruling.
- The re-extracted PT-K graph has no cross-owner execution cycle.

## Completion

One checked Rust execution kernel replaces the old context/span/padding/lazy
routes, and the deleted symbols are absent rather than aliased.
