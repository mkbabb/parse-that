# U.W5 — acyclic generated bootstrap and fixed point

## Goal

Generate regex syntax through the declared grammar route and prove an empty-output
fixed point without hidden host-language rewriting.

## Work

1. Define seed, stage-1, and self-hosted artifacts and exactly which executable
   consumes each. The seed is immutable data, not an alternate production parser.
2. Replace the broken bootstrap script with one checked command graph; remove
   Python rewrites, cargo-expand ambiguity, and untracked patch steps.
3. Emit semantic manifests containing source, grammar, Unicode, generator,
   toolchain, command, and output digests. Consumers verify them before compile.
4. Start from empty generated directories, produce stage-1, regenerate with the
   produced engine, and require two consecutive byte-identical stages.
5. Add negative mutation probes for stale source, wrong Unicode, wrong generator,
   manual output edit, and missing manifest.

## Gates

- Bootstrap reaches a byte-identical fixed point twice from clean output roots.
- Every generated byte is mapped to one source and consumer; undeclared output and
  undeclared manual copy are RED.
- The generator dependency graph is acyclic when generation-time and runtime edges
  are projected separately.
- Packed crates contain the exact proven files and no seed-facing private organ.

## Completion
