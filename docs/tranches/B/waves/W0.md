1. `npx tsc --noEmit --project tsconfig.json`, focused prototype suites,
   package suites and build all pass with exact pass/skip counts.
2. Hostile vectors prove exact slots including
   `[undefined, false, 0, "", span]`, complete scalar rollback, monotone
   frontier/work/max-depth, diagnostic truncation and run isolation.
3. Bounded recursion yields a typed fault before host `RangeError`; raw memo
   cells cannot leak across sources/runs.
4. Unordered composition proves deterministic `&&`/`||` behavior without
   state explosion above the declared cap.
5. Value's sole source-direct CSS grammar covers the frozen standards
   denominator and named extensions with WPT/browser differentials.
6. `jsonParser` consumes the same generic runtime and matches frozen JSON
   vectors and `JSON.parse` products.
7. Both consumer diffs prove net deletion/consolidation; no token/scanner,
   serializer, alias, shim or fallback path remains.
8. At every declared scale, the exact-bootstrap 95% low is ≥10× for equal
   values, spans, diagnostics, recovery and failure behavior. Result
   materialization is timed, not excluded.
9. CPU, heap, allocation, hidden-class/IC, optimization/deoptimization and
   GC outputs are sealed to source, data, Node/V8, order and batch inputs.
10. Two hostile audits accept the same source and immutable unpublished
    candidate tarball.
11. Value and JSON consume that exact tarball SHA and return receipts.
12. `/utils` has two exact consumer receipts or is absent from the pack.
13. The release tag/tarball matches the admitted commit; Value rebinds to
    the released coordinate and reruns its full gates green.
14. BBNF receives only the post-W3 frozen generic ABI receipt.
15. `git diff --check`, manifest verification, clean tracked status and the
    integrity sweep are green.
