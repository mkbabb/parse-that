# P7 — external source, interface, and prose verifier

Status: `PAPER_ONLY / ZERO_CREDIT / SOURCE_WITHHELD`

Future source budget: `1 module / 60 nonblank noncomment LOC maximum`.
Paper budget: `100 nonblank lines maximum`.

## External boundary

P7 is outside every candidate module and accepts only frozen source bytes,
P0–P7 interface bytes/hashes, prose bytes/hashes, the paper/source manifests,
and immutable owner pins for the AST parser/toolchain. Candidate code cannot
invoke, configure, suppress, replace, or self-approve it. The verifier parses
source with the pinned AST tool and derives module membership, declarations,
exports, imports, symbol ownership, call graph, data graph, literal tables,
predicate/injector reachability, interface edges, and nonblank/noncomment LOC.

It requires exactly eight future modules and the per-interface ceilings
`120/170/110/160/70/60/100/60`, total `850`. Generated bytes, embedded tables,
schemas, copied fixtures, and helper modules count in full. It verifies that
the authenticated declaration is consumed, each cross-interface edge is
present once at each owner, P0–P6 claims match exact source hashes/symbols, and
prose adds no row, status, mechanism, exception, or favorable conclusion.

Forbidden graph edges are scanner/token/index/tape/CST/forest, event/region
projection, runtime grammar/compiler/table interpreter, opcode/PC/VM loop,
generated grammar/source, fallback/dual/scalar path, candidate self-verifier,
module-global mutable parse state, parser-to-Fourier, CSS grammar in parse-that,
and any unlisted interface edge. Every failure has a fixed verifier-owned code;
message strings are explanatory only.

## Paper review obligations

Reviewers must reject missing/extra modules, unpinned AST tooling, source/prose
hash drift, unconsumed declaration, one-sided interface rows, graph-edge alias,
budget exclusion, helper hiding, candidate-controlled policy, or self-reported
GREEN. P7 is a contract only; no verifier or AST analysis runs in v1.
